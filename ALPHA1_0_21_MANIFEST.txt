Integrated contracts under test:
- Server/backend systems remain authoritative for network physics, metrology, propagation, commissioning and event evidence.
- Client HMIs render synchronized evidence and diagnostics; they do not run a second solver or fabricate history/noise.
- Physical RX/TX endpoints correspond to real backend reads/writes and collision-safe routing.
- Redstone remains a coarse 0..15 control medium; Lapis is a higher-resolution 0..100 information domain; explicit conversion exposes source spacing and quantization loss.
- Copper remains a power/load domain with V, equivalent resistance, current, power, commissioning and evidence-readiness semantics kept separate from protection reliability.
- Instrument shielding changes deterministic interference confidence only when actual local exposure exists; it does not randomly corrupt samples or redefine topology validity.
- 8-bit Bus, Serial and Differential communication preserve distinct payload/timing/integrity tradeoffs.
- Guided optical diagnostics use the existing discrete 0..15 model and explicit processor boundaries; no fake dB model is introduced.
- Pneumatic diagnostics use the existing lumped pressure/line-loss/regulation model; cylinder response is pressure-dependent without pretending to be CFD.
- RadioKernel remains the sole owner of radio range, obstacle loss, deterministic fading, adjacent-channel interference, collision, decode margin and latency.
- Commissioning/operations evidence stays bounded and does not grow without limit.
