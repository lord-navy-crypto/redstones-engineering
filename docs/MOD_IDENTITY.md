# Redstone Systems Engineering (RSE)

Mod ID: redstoneengineering
Display name: Redstone Systems Engineering
Short name: RSE
Version: 0.1.0-alpha.3
Minecraft: 1.21.1
Loader: NeoForge

Tagline:
Vanilla redstone, extended into engineering systems.

Description:
Redstone Systems Engineering is a vanilla-first engineering extension for
Minecraft redstone. It preserves redstone's native 0–15 signal language and
tick-based behavior while adding instrumentation, signal conditioning,
sampling, pulse processing, PWM control, sensing, and engineering diagnostics.
