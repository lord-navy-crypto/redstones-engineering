Redstone Systems Engineering (RSE) 1.0.21-alpha — zsh / Terminal install & verification

Target:
- Minecraft 1.21.1
- NeoForge 21.1.249
- Java 21
- RSE artifact: 1.0.21-alpha

Required dependencies:
- JEI 19.27.0.336
- Jade 15.10.6
- GeckoLib 4.9.2
- Cloth Config 15.0.140

RSE does not bundle dependency jars. NeoForge must be able to load all required dependencies.

1) Open the repository and stop Gradle:

cd ~/redstones-engineering
./gradlew --stop

2) Fetch the release candidate:

git fetch origin
git checkout release/1.0.21-alpha-rc1
git reset --hard origin/release/1.0.21-alpha-rc1

3) Confirm the version:

grep '^mod_version=' gradle.properties

Expected:
mod_version=1.0.21-alpha

4) Run release verification:

python3 tools/rse_repo_verify.py
python3 tools/test_rse_integrated_demo.py
python3 tools/test_rse_signal_processing_lab.py
python3 tools/rse_pid_actuator_dynamics_verify.py
python3 tools/rse_ninth_ten_control_pneumatic_verify.py
python3 tools/rse_alpha1021_release_verify.py

5) Compile/test/build:

./gradlew test --no-daemon --stacktrace
./gradlew compileJava --no-daemon --stacktrace
./gradlew clean build --no-daemon --stacktrace

6) Optional legacy GameTest diagnostic (non-blocking for Alpha 1.0.21):

./gradlew runGameTestServer --no-daemon --stacktrace

A non-zero result here is tracked as historical runtime-test debt and does not block an otherwise passing Alpha 1.0.21 release build.

7) Launch the client for the real-use smoke test:

./gradlew runClient --no-daemon --stacktrace 2>&1 | tee latest.log

In-game smoke-test focus:
- Integrated Commissioning Bench V2
- Servo / PID actuator dynamics and feedback
- Pneumatic linear actuator cell
- Signal Processing Laboratory
- Broken/misrouted connection behavior
- JEI/Jade/GUI usability

If startup or runtime fails, preserve latest.log.

Scope:
This release candidate preserves the complete-chain + actuator-deepening era and intentionally excludes the later shared Engineering Workbench / generic LAB UI redesign.
